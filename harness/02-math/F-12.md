# F-12 — Pemisahan ulang pasangan AO–TC bertanggal sama

Class: A (identitas aljabar atas regresor baku)
Status: PROVEN (identitas, bukti di bagian 3); korelasi regresor CITED-VERIFIED + diperiksa numerik
Dipakai oleh: FR-017 (`treat_outliers()` untuk `TramoOutliers`, `collinear_pairs()`, `collinear_shift()`)

## 1. Spesifikasi presisi
- Regresor (Chen dan Liu 1993; X-13ARIMA-SEATS Reference Manual, bab
  `regression`): AO_t(t₀) = 1{t = t₀}; TC_t(t₀) = r^(t−t₀) 1{t ≥ t₀};
  LS_t(t₀) = 1{t ≥ t₀}. Laju TC: TRAMO r = 0,7; X-13 r = 0,7^(12/f)
  (0,343 untuk triwulanan), lihat `tc_rate()`.
- Masukan: koefisien a (AO di t₀) dan c (TC di t₀) dari model regARIMA,
  himpunan jenis yang dibuang R ⊆ {AO, TC, LS}.
- Keluaran: efek yang dikurangkan dari seri, E_R(t).

## 2. Identitas
Efek gabungan pasangan:
  a·AO_t(t₀) + c·TC_t(t₀) = (a + c)·AO_t(t₀) + (c r)·TC_t(t₀ + 1)   untuk semua t.

## 3. Bukti
- t < t₀: kedua ruas 0.
- t = t₀: ruas kiri a + c·r⁰ = a + c; ruas kanan (a + c) + 0 (TC(t₀+1) nol di t₀).
- t > t₀: ruas kiri 0 + c r^(t−t₀); ruas kanan 0 + c r · r^(t−t₀−1) = c r^(t−t₀). ∎

Akibatnya nilai cocokan model dan sisaannya tidak berubah; yang berubah hanya
pembagian efek ke dalam jenis. cyclind memakai bentuk kanan: AO memuat
seluruh simpangan di t₀ (yang diukur langsung oleh data di t₀), TC memuat
dinamika sesudah t₀. Aturan pembuangan (AC-FR-017.1):
- AO ∈ R, TC ∉ R: E = E_lain + (a + c)·1{t = t₀} = E_lama + c·1{t = t₀};
- TC ∈ R, AO ∉ R: E = E_lain + c r^(t−t₀) 1{t > t₀} = E_lama − c·1{t = t₀};
- keduanya atau tidak satu pun: E = E_lama (identitas).
Jadi koreksinya s·c·1{t = t₀} dengan s = 1{AO ∈ R} − 1{TC ∈ R}.

## 4. Korelasi regresor (mengapa hanya tanggal yang sama)
Sesudah selisih pertama, untuk seri panjang (pusat diabaikan):
  ⟨ΔAO, ΔTC⟩ = 1 − (r − 1) = 2 − r, ‖ΔAO‖² = 2,
  ‖ΔTC‖² = 1 + (1 − r)² Σ_{k≥0} r^{2k} = 2/(1 + r),
sehingga ρ = (2 − r)√(1 + r)/2: 0,960 (r = 0,343) dan 0,847 (r = 0,7).
Hitungan numerik (n = 200, `/tmp` skrip verifikasi, lihat 04-test-plan):

| r | d | AO di t₀−1 | AO di t₀ | AO di t₀+1 |
|---|---|---|---|---|
| 0,343 | 1 | −0,579 | 0,960 | −0,250 |
| 0,343 | 2 | −0,751 | 0,974 | −0,487 |
| 0,700 | 1 | −0,652 | 0,847 | −0,059 |
| 0,700 | 2 | −0,819 | 0,916 | −0,352 |

Pada tanggal bertetangga korelasinya lebih lemah, dan kedua regresor
menempati tanggal yang berbeda (AO hanya di satu tanggal yang tidak sama
dengan awal TC), sehingga pembagian efek per tanggal tidak ambigu; pasangan
itu tidak dipisahkan ulang (ADR-012).

## 5. Verifikasi numerik
- Identitas: selisih maksimum kedua ruas 5,6e-17 (a = 3, c = −6, r = 0,343).
- `test-x13-fixes.R`: efek yang dibuang sama dengan rumus bagian 3 (galat
  < 1e-10) untuk R = {AO}, {TC}, {AO, TC}; korelasi yang dilaporkan sama
  dengan bentuk tertutup ρ (galat < 0,01 untuk n = 48).

## Critic review
Ditinjau ulang dari berkas (tanpa isolasi konteks; tidak ada alat subagen):
identitas diperiksa per kasus t < t₀, t = t₀, t > t₀; tanda koreksi s
diperiksa untuk keempat himpunan R; kasus t₀ = n (TC' mulai di luar sampel)
benar karena prakiraan TC memakai efek TC di n dikali r^h, sama untuk kedua
bentuk. Tidak ada temuan terbuka.
