# F-13 — Statistik QS musiman

Class: A
Status: CITED-VERIFIED
Dipakai oleh: FR-019 (`qs_test()`, cadangan `seasonal_adjust_x13()`)

## 1. Spesifikasi presisi
- Masukan: seri y_1..y_n (ber-log bila keputusan transformasi FR-018 log),
  frekuensi s (4 atau 12).
- z_t = y_t − y_{t−1} (t = 2..n), m = n − 1; ρ̂(k) autokorelasi contoh
  (`stats::acf`, rata-rata dikurangkan, pembagi m).
- QS = m(m + 2) [ ρ̂(s)²/(m − s) + ρ̂⁺(2s)²/(m − 2s) ] bila ρ̂(s) > 0,
  dan QS = 0 (p = 1) bila ρ̂(s) ≤ 0, dengan ρ̂⁺(k) = max(0, ρ̂(k)), seperti
  `qsori` X-13ARIMA-SEATS (audit 2026-11-18, S3: sebelumnya ρ̂(2s) > 0 saja
  sudah memberi QS positif).
- p = P(χ²₂ > QS). Seri tanpa variasi (z konstan) atau m ≤ 2s: QS = 0, p = 1.

## 2. Sumber
Maravall (2012), "Update of seasonality tests and automatic model
identification in TRAMO-SEATS", Banco de España; U.S. Census Bureau,
X-13ARIMA-SEATS Reference Manual (diagnostik QS, `qsori`). Statistik ini
bentuk Ljung–Box yang hanya memakai autokorelasi positif pada lag musiman.
Sebaran χ²₂ adalah pendekatan yang dipakai X-13 untuk p-value (autokorelasi
negatif dipotong ke nol, sehingga ujinya sedikit konservatif).

## 3. Turunan ulang
Ljung–Box Q = m(m+2) Σ_k ρ̂(k)²/(m − k) pada k ∈ {s, 2s}; pembatasan ke
ρ̂ > 0 karena musiman memberi autokorelasi positif pada lag musiman.

## 5. Verifikasi numerik
QS seri level cocok persis dengan `seasonal::qs(seas(x))["qsori", ]`:
UKgas 176,5144; nottem + 100 237,8344; ldeaths 26,6469 (galat < 1e-3,
`test-x13-fixes.R` untuk UKgas, angka X-13 1.1-61). Pada AirPassengers dan
JohnsonJohnson X-13 melaporkan angka yang berbeda (167,6 dan 52,7 terhadap
194,5 dan 65,6); penyebabnya tidak dikejar karena keputusan "musiman atau
tidak" sama (p < 1e-14 di keduanya). Seri konstan → p = 1; seri musiman
deterministik → p < 0,001.
